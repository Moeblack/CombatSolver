# Combat Solver v0.25.0 药水策略与搜索体验升级

## 药水策略

- 强制使用和禁用保护现在会按药水槽位与药水身份持久保存；同一瓶药进入下一场战斗后仍保留玩家选择。
- 药水被使用或槽位换成新药后，旧策略不会套到新药上；新获得的药水仍默认智能使用。
- 智能搜索改为单条“无药 → 恰好一瓶 → 恰好两瓶……”梯度；同一药量下所有药水在一次搜索中共同竞争，不再逐瓶重复搜索。
- 无药路线存活时，每预计损失 `9 HP` 才开放一瓶普通药的搜索额度，并在第一条达到对应省血门槛的路线停止；无药会死亡时则逐层搜索到第一条生还路线。
- 搜索耗时、世界线数量和进度条在各梯度间保持累计，不再表现为反复从头计算。
- 药水策略改为主面板右侧的单列窄侧栏；药水策略、设置和收起按钮保持在原来的主面板右上角。
- 搜索期间会标明正在搜索无药路线或恰好几瓶药的路线。
- 战损提示补充“不满意时提高性能预设重试”和“点击可直接跳转”的说明。

## 内存管理

- 默认交由运行时自动管理垃圾回收，不再由求解器建立 No-GC 区域或在战斗结束集中回收。
- 主界面新增“手动 GC”按钮，需要时可由玩家主动执行完整回收。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
