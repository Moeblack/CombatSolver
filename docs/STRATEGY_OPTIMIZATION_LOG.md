# 策略优化日志

本日志逐项记录玩家“找到更优世界线”样例带来的策略认识、求解器改动和同根战损验收。测试是否通过仍记录在 `docs/TEST_MATRIX.md`；搜索性能夹具不承担策略质量记录。

## 记录口径

- 只比较同一战斗根、同一 RNG 和同一药水政策下的整场战损。状态无法严格导入时明确标记“未验收”，不使用近似重建结果。
- “优化幅度”是“优化前求解器战损 - 当前求解器战损”；“相对人工”是“人工战损 - 当前求解器战损”。正数表示当前求解器更好。
- 一个样例引出的多项改动按组合结果验收；没有隔离实验时，不把总收益虚构成某一项改动的独立收益。
- 中间实验和失败结果一并保留，用于区分“动作顺序看起来正确”和“整场路线真正追平人工”。

## `fdddbd5dd1164e5cbe63cdeefa157f08`：过牌与减费组合

来源是静默猎手对永世沙漏的报告。玩家指出求解器没有先过牌再使用子弹时间；严格导入检查点后，优化前默认档路线预计战损为 `34`，玩家路线战损上界为 `6`。

### 求解器学到了什么

- 只按动作的即时伤害、格挡和资源收益截取分支，会过早丢弃“先扩大手牌、再统一减费”的启动动作。过牌与减费的价值必须按当前能量下整手牌的可兑现收益评估，不能只给单张牌固定加分。
- 先验只负责让启动动作活到下一层；真实抽牌、减费和后续出牌结果才是后验。首动作正确不代表整场路线质量已经改善。
- 药水路线只按“已使用几瓶”合并会丢掉具体药水的后续窗口；药水身份需要进入有限的保路代表。
- 增加策略分支家族后，旧默认容量不足以让正确组合稳定走完整场。默认 Medium 需要承接原 High 的 Beam 和分支容量。

### 做了什么改动

- 卡牌展开先保留即时防御、即时输出、过牌与资源、持续成长、控制、目标移除和生命投资等策略家族代表，再以即时总分填满剩余分支。
- 新增当前能量或星能约束下的整手牌可达价值，以及零费可执行牌数，专门保留过牌、减费和战术启动路线；最终路线排序仍使用真实模拟结果。
- 药水保路增加具体药水身份代表，避免不同药水路线只因已用数量相同而互相覆盖。
- Beam 与选择分支容量整体上移一档：Medium 使用原 High 容量，即 `24/60` Beam、`20/32` 卡牌分支、`10/18` 牌堆选择分支和 `12/24` 手牌选择分支；节点、时间和 No-GC 预算保持 Medium 原值。

### 实验过程与验收

| 阶段 | 结果 | 结论 |
| --- | ---: | --- |
| 优化前默认档 | 战损 `34` | 未追平人工 |
| 仅增加手牌战术先验 | 首动顺序正确，整场战损仍为 `34` | 只能保住入口，不能保证完整路线 |
| 增加药水身份保路 | 战损 `17` | 有改善，仍未追平人工 |
| 原 High 容量 | 战损 `3` | 组合路线完整进入终局 |
| 当前默认 Medium | 战损 `3`，第 4 回合无药击杀 | 比人工上界少 `3` 战损 |

当前源码回归使用 Medium、Smart、DOP4 和 `8 GB` No-GC；首动独门技术，随后使用子弹时间，完整 `ContinuationStamp` 一致。预计战损仍为 `3`、第 4 回合击杀，runId `3e1f05195228471bbea6cafaabcab1d7`。

## `0f7f827883b2410b971e030839827b4f`：防御、留牌与跨回合资源

来源是亡灵契约师对蜂群术士的报告。原求解器路线战损 `57`；玩家第二回合补打护卫和防御、第三回合只打唤起后停手，最终战损 `0`。正式验收使用报告原档 VeryHigh、禁用药水、DOP4 和 `8 GB` No-GC。

### 求解器学到了什么

- “当前回合不掉血”不是充分条件。两条同样无伤的路线，可能因下一回合手牌、奥斯蒂生命和召唤资源不同而产生完全不同的终局战损。
- 获得跨回合资源后立即停手是独立策略，不能只保留随后继续输出的贪心后继；缩放、资源和控制路线都需要结束回合后的真实状态作为后验。
- 奥斯蒂当前生命、最大生命和下回合召唤不是附属状态。其价值取决于牌组里可兑现的奥斯蒂攻击，必须参与防御与资源路线比较。
- `ApplyRetain` 是会改变后续搜索空间的选牌。此前它被排除在选牌分支保留之外，`响指→保留某牌` 会像普通低即时收益动作一样被剪掉。
- 已击杀路线仍要按累计战损比较。当前生命经过治疗后相同，不代表两条路线实际承受的战损相同。

### 做了什么改动

- 深搜按药水使用数量分别保留最低累计战损的已击杀路线，胜利候选依次比较累计掉血、最大生命、长期资源、药水成本和卖血。
- 每个药水组分别保留缩放、资源、控制和“刚获得未来资源后停手”的结束回合代表；评价使用真实结束回合模拟，而不是给动作加固定分。
- 资源评估加入奥斯蒂当前/最大生命；下回合召唤价值按可用奥斯蒂攻击数量折算，并进入防御、资源与 Pareto 比较。
- 真正的回合边界额外保留一条高生命、高奥斯蒂生命且下一回合手牌可用性好的路线。
- 将 `ApplyRetain` 纳入持续选牌分支通道，保留不同留牌目标及其后续路线。
- 严格回放导入补齐遗物、Power、卡牌局部关键词、回合抽牌历史和旧版 RNG 状态戳兼容；验收始终使用报告原始完整 RNG，不使用近似状态。

### 实验过程与验收

| 阶段 | 结果 | 结论 |
| --- | ---: | --- |
| 报告原求解器 | 战损 `57` | 第二回合漏打防御，未追平人工 |
| 当前 Medium 基线 | 战损 `3` | 已明显改善，但与报告原 VeryHigh 预算不可直接作为正式对照 |
| 当前 VeryHigh 基线 | 战损 `39` | 更宽搜索反而让高即时分路线挤掉长期路线 |
| 加入结束回合资源后验 | 战损 `6` | 第二回合防御动作已与人工一致 |
| 加入奥斯蒂资源量化 | 战损 `1` | 完整首根仅剩一次掉血；人工第二、三回合检查点均可独立找到 `0` 战损路线 |
| 把留牌价值加入全局 Pareto | 战损 `10` | 粗粒度通道挤掉击杀节奏，撤回 |
| 每层强保留牌节点 | 战损 `45` | 中间节点长期占用 Beam，撤回 |
| 仅在回合边界保手牌，并补全 `ApplyRetain` 选牌分支 | 战损 `0`，第 13 回合无药击杀 | 完整首根追平人工 |
