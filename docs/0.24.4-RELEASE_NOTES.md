# Combat Solver v0.24.4 药水策略与内存管理修复

## 药水策略

- 强制使用和禁用保护现在会按药水槽位与药水身份持久保存；同一瓶药进入下一场战斗后仍保留玩家选择。
- 药水被使用或槽位换成新药后，旧策略不会套到新药上；新获得的药水仍默认智能使用。
- Smart 主搜索和后续药水复核现在共享当前性能预设的总时间，不再让每轮药水补查各自重新使用一整份时间预算。
- 搜索耗时、世界线数量和进度条在药水补查期间保持累计，不再表现为反复从头计算。

## 内存管理

- 合并 Moeblack 提交的 PR #25：默认交由运行时自动管理垃圾回收，不再由求解器建立 No-GC 区域或在战斗结束集中回收。
- 主界面新增“手动 GC”按钮，需要时可由玩家主动执行完整回收。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
